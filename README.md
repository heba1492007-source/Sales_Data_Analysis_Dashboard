# Sales Data Analysis Dashboard

## Project Description
This project analyzes sales data using Python and Pandas.

## Features
- Read CSV data
- Clean data
- Analyze sales
- Calculate KPIs
- Generate charts
- Save charts as PNG files

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
Sample Superstore Dataset

## Output
- Sales by Category
- Sales by Region
- Monthly Sales
